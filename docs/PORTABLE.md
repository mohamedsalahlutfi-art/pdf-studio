# نسخة Salah PDF المحمولة (Portable — Windows x64)

نسخة مستقلة تعمل بفك الضغط والتشغيل، دون تثبيت أو Node.js أو Git أو إنترنت.
لا تمسّ شجرة التطوير: كل المخرجات تحت `dist-portable/` (مستثناة من Git).

## إعادة البناء
```bash
npm run portable
```
المخرجات:
- `dist-portable/Salah-PDF-Portable-<version>.zip` — الملف النهائي للتوزيع.
- `dist-portable/stage/Salah PDF <version>/` — المجلد المحمول قبل الضغط، وبداخله
  `Salah PDF.exe` و `resources/app.asar` و `README.txt` و `LICENSE.txt`.

كيف يعمل السكريبت (`scripts/build-portable.mjs`):
1. `npm run build` لتجهيز حِزم `out/`.
2. تعبئة كود الإنتاج فقط (`out/` + manifest) في `app.asar` — بلا مصدر أو اختبارات.
3. تنزيل نسخة Electron لويندوز الرسمية (تُخزَّن في `.cache`).
4. إعادة تسمية `electron.exe` إلى `Salah PDF.exe`، وحذف `default_app.asar`،
   ووضع `app.asar`.
5. كتابة `README.txt` و `LICENSE.txt` و `VERSION`.
6. ضغط المجلد في ZIP (كاتب ZIP داخلي، بلا اعتماديات).

## مكان بيانات المستخدم
في وضع الإنتاج يحفظ البرنامج إعداداته ومكتبة التواقيع في مجلد `data` بجانب
الملف التنفيذي (العملية الرئيسية `usePortableDataDir`). لو كان المكان للقراءة
فقط، يرجع تلقائياً إلى مجلد بيانات المستخدم في النظام دون فشل الحفظ. ملفات PDF
المحفوظة تذهب إلى التنزيلات أو حيث يختار المستخدم "حفظ باسم".

## الاختبارات على التوزيعة (مُنفّذة)
السكريبتات في `tests/e2e/` تعمل على النسخة المعبّأة نفسها (الـ asar المشحون
مركّب على نسخة Electron)، وليس على نسخة التطوير:
- `packaged.cjs`: فتح PDF من مسار فيه مسافات، تظليل نص، وضع ختم، حفظ ودمج
  التعليقات وإعادة الفتح، ضغط ذكي (تحقّق من صِغَر الحجم)، وتصدير PNG.
- `portable-data.cjs`: ثبات الإعدادات بعد الإغلاق وإعادة التشغيل، وكتابة مجلد
  `data` بجانب البرنامج (لا شيء في بروفايل الجهاز).

تشغيلها محلياً (بعد `npm run portable`):
```bash
npm run test:portable      # يحتاج بيئة يمكنها تشغيل Electron
```

## قيود موثّقة بصدق
- **لم يُشغَّل ملف Windows التنفيذي على نظام Windows فعلي في بيئة البناء**، لأن
  البناء تمّ على Linux. تم التحقق من محتوى التوزيعة (نفس `app.asar` المشحون)
  بتشغيله على نسخة Electron، وهو كود مطابق عبر المنصّات. يُنصح بتشغيل
  `Salah PDF.exe` مرة على Windows للتأكيد النهائي.
- أيقونة الملف التنفيذي ومعلومات إصداره قد تظهر باسم Electron الافتراضي، لأن
  ختم الأيقونة يتطلب أدوات Windows (rcedit/Wine) لم تتوفر وقت البناء. هذا تجميلي
  ولا يؤثر على التشغيل.
- التغليف وASAR يصعّبان قراءة الكود لكنهما لا يمنعان الهندسة العكسية منعاً مطلقاً.
- لا يحتوي البرنامج على نظام تفعيل أو اتصال إجباري بالإنترنت.
