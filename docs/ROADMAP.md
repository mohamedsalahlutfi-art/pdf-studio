# Salah PDF — خارطة الطريق وسجل التقدم

هذا هو السجل المركزي الدائم للمشروع. كل ميزة متفق عليها موجودة هنا حتى تُنفّذ أو
يُوضَّح قيد تقني يمنعها. لا تُحذف بنود ولا تُختزل. أي جلسة لاحقة تكمل من هنا.

آخر commit مرجعي للجرد: `967f6d3` ← يُحدَّث مع التقدم.

## المعمارية (مرجع سريع)

- **Electron + React + TypeScript + Vite** (`electron-vite`).
- **العملية الرئيسية** `src/main`: النوافذ، القوائم، فتح/حفظ الملفات، بروتوكول `app://`.
- **preload** `src/preload`: جسر آمن محدود (contextIsolation + sandbox).
- **الواجهة** `src/renderer`: React. الحالة في `store/useApp.ts` (zustand).
- **منطق PDF** منفصل عن الواجهة: `lib/buildPdf.ts`, `lib/exportDocument.ts`,
  والعمليات الثقيلة في Web Worker `workers/pdf.worker.ts`.
- **العرض**: pdf.js في worker خاص به؛ عرض افتراضي (صفحات الـ viewport فقط).
- **نموذج المستند**: قائمة صفحات، كل صفحة تشير لمصدر PDF + تدوير + تعليقات.
  كل تعديل ينتج DocState جديد ⇒ تراجع/إعادة بلا حدود.
- **الحفظ**: مستند غير معدّل ⇒ البايتات الأصلية (التواقيع الرقمية تبقى سليمة)؛
  غير ذلك يُعاد بناؤه بـ pdf-lib في worker.

## المخاطر والتعارضات المعروفة
- **الحفاظ على التواقيع الرقمية**: أي إعادة بناء (ضغط/دمج) تكسر توقيعاً رقمياً
  سابقاً على الملف. الحالي: مستند غير معدّل يُحفظ بالبايتات الأصلية. الضغط سيُنتج
  نسخة جديدة ⇒ يجب تنبيه المستخدم أن التوقيع الرقمي السابق قد يسقط.
- **مربعات النص كصور**: تحافظ على التشكيل لكنها غير قابلة للبحث/النسخ (موثّق).
- **التشفير**: pdf-lib لا يكتب/يقرأ ملفات مشفّرة ⇒ مسار كلمات المرور يحتاج
  مكتبة/مسار منفصل (يُقيَّم في القسم 5).
